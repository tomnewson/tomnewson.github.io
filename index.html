Project Description
Log Everything The everything app. General experience logging social media with Typescript React front-end and Firebase back-end (as a service).
Boids Javascript simulation of Reynolds' Boids with predator-prey, food, and wall mechanics for user interactivity.
Synaesthesia Simulations of sound-colour/shape synaesthesia (chromaesthesia) in Python and Godot. University of Manchester final year project, accompanied by paper documenting psychology-grounded approach.
Boids + Synaesthesia Responsive boids simulation that reacts to system/microphone audio, loosely following synaesthetic principles from previous work. Built in Rust.
Inanna Windows/MacOS app with a Rust backend and C# Avalonia front-end that provides a simple interface over CLI tools yt-dlp and ffmpeg to download videos in their most compatible codecs.
